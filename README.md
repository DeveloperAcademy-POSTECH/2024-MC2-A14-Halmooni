## :pushpin: Features

- 무니 모드
	- 할머니께 사랑을 표현할 동기부여를 제공하는 **목표관리 뷰**
	- 할머니께 사랑을 표현한 편지들을 모아볼 수 있는 **모아보기 뷰**
	- 할머니께 편지를 작성하는 **편지 작성 뷰**
	- 할머니께서 보내신 음성녹음들을 열람할 수 있는 **From.할머니 뷰**

- 할머니 모드
    - 무니가 보낸 편지들을 모아볼 수 있는 **모아보기 뷰**
    - 무니가 보낸 편지의 상세내용을 확인할 수 있는 **상세보기 뷰**
    - 무니에게 음성녹음을 보낼 수 있는 **음성녹음 기능**
